🌱 **ROOTWARDEN — Defend the Last Seed through ten nights of blight.** An original tower-defence game: plant five kinds of wardens on soil plots beside the blight's road, earn seeds from every kill, upgrade your garden, and call down the Dawnburst to hold the road. Ten waves, six blight kinds, a boss on wave 10, and one Seed to save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests — every file the game loads lives under `game/`.
